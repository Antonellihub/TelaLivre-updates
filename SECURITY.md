# Política de segurança do Tela Livre

## Versões atendidas

As correções de segurança são disponibilizadas na [versão estável mais recente do Tela Livre](https://github.com/Antonellihub/TelaLivre-updates/releases/latest). Na publicação desta política, a versão atendida é a **0.25.5**.

Para receber as correções em uma instalação anterior, atualize para a versão estável mais recente.

## Relatar uma vulnerabilidade

Use o [formulário de relato privado do GitHub](https://github.com/Antonellihub/TelaLivre-updates/security/advisories/new) e entre na sua conta para enviar o relato.

Inclua a versão do Tela Livre, uma descrição do problema, o impacto observado e os passos mínimos para reproduzi-lo. Remova credenciais, códigos de salas privadas e dados pessoais de logs e anexos.

Use a conversa privada do GitHub para complementar o relato enquanto a falha é analisada.
